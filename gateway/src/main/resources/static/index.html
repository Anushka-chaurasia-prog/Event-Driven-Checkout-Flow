WHAT WE GUARANTEE

SAGA ORCHESTRATION

Order service orchestrates the lifecycle: stock reservation, credit authorization, and automatic rollback compensations if any step fails.

TRANSACTIONAL OUTBOX

Domain state changes and outbox event records commit atomically to PostgreSQL in a single ACID transaction, polled and relayed asynchronously to Kafka.

IDEMPOTENT HANDLERS

Every message carries a unique correlation and idempotency key. Duplicate Kafka deliveries or network retries are detected and safely suppressed.
